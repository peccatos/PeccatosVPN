# Каталог профилей VLESS

Здесь `vpn-helper` ищет VLESS-профили для `--tunnel --profile` и TUI-проверок.

## Формат

Один файл = один или несколько профилей, по одному `vless://...` на строку:

```
vless://<uuid>@<host>:<port>?security=reality&pbk=...&fp=chrome&type=tcp&sni=...#Подпись
```

UTF-8 (с BOM или без — BOM отбрасывается автоматически). Расширение файла любое текстовое (`.txt`, `.vless` и т.п.).

⚠️ **Файлы с ключами не коммитятся** (см. `.gitignore`) — UUID в ключе это секрет.
Скачанные из TUI публичные ключи (клавиша `g`, источник vless-checker) живут часами;
кладите их сюда локально для теста.

## Где брать ключи

- TUI: `vpn-helper --tui`, клавиша `g` — свежие ключи из проверенных источников
- tiagorrg.github.io/vless-checker — обновляется каждые ~30 минут
